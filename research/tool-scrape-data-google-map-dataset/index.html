Kỹ Thuật Cốt Lõi: Vượt Bức Tường 120 Kết Quả Bằng Thuật Toán Quadtree

Bản chất vấn đề: Tại sao Google cắt ở con số 120?

Khi tìm kiếm một cụm từ trên Google Maps (ví dụ: quán cafe ở TP.HCM), Google Maps UI chỉ cuộn tối đa khoảng 6 - 7 lần phân trang, đạt đúng 120 kết quả rồi ngắt thông báo: "Bạn đã xem hết danh sách". Dù thực tế TP.HCM có hơn 15.000 quán cafe, bạn sẽ bỏ sót 99% dữ liệu nếu chỉ quét một lần từ trung tâm!

Giải pháp: Phân Vùng Lưới Đệ Quy (Quadtree Spatial Partitioning)

  • Xác định khung tọa độ bao quanh thành phố: [MinLat, MinLng, MaxLat, MaxLng].
  • Chia nhỏ bản đồ thành các ô lưới ban đầu (ví dụ: kích thước 2km x 2km).
  • Nếu một ô lưới trả về < 100 kết quả: Vùng này thưa thớt, lưu toàn bộ dữ liệu và dừng lại.
  • Nếu một ô lưới chạm ngưỡng ≥ 115 kết quả: Vùng này mật độ cao (trung tâm), thuật toán tự động bổ đôi thành 4 ô con (Quadtree) và tiếp tục quét đệ quy cho đến khi vét kiệt 100% dữ liệu.
Minh Họa Cơ Chế Phân Vùng Quadtree Trên Bản Đồ
🐍 Python Script: Sinh Lưới Tọa Độ Tự Động Theo Bước Nhảy Km 
import math

def generate_bounding_box_grid(min_lat, min_lng, max_lat, max_lng, step_km=1.5):
    """
    Chia bản đồ thành lưới tọa độ tâm điểm dựa trên khoảng cách km.
    1 độ vĩ tuyến ~ 111 km. 1 độ kinh tuyến ~ 111 * cos(lat) km.
    """
    grid = []
    lat_step = step_km / 111.0
    
    current_lat = min_lat
    while current_lat <= max_lat:
        lng_step = step_km / (111.0 * math.cos(math.radians(current_lat)))
        current_lng = min_lng
        while current_lng <= max_lng:
            grid.append({
                "center_lat": round(current_lat + lat_step/2, 6),
                "center_lng": round(current_lng + lng_step/2, 6),
                "zoom": 15
            })
            current_lng += lng_step
        current_lat += lat_step
    return grid

# Ví dụ: Sinh lưới bao phủ toàn bộ Thành Phố Đà Nẵng (bước nhảy 1.5 km)
danang_grid = generate_bounding_box_grid(15.95, 108.10, 16.15, 108.28, step_km=1.5)
print(f"Tổng số điểm tọa độ quét: {len(danang_grid)} ô.")

Chiến Lược Chống Khóa IP & Vượt Anti-Bot Fingerprint

🌐 1. Chiến Lược Mạng Proxy (Bắt Buộc Residential)
Tuyệt đối KHÔNG dùng Datacenter Proxy: Các dải IP từ AWS, DigitalOcean, Hetzner, Google Cloud đều bị Google Maps nhận diện trong blacklist ASN và khóa CAPTCHA sau 15 - 20 lượt query.
Bắt buộc dùng Rotating Residential Proxy: Sử dụng IP dân cư thực tế từ các nhà mạng (Viettel, VNPT, Comcast, AT&T). Cấu hình xoay IP sau mỗi 5 - 10 request hoặc theo session.

Các nhà cung cấp khuyên dùng: Webshare (tiết kiệm, ~$3/GB), Smartproxy (~$4.5/GB), Bright Data (cao cấp, sạch nhất).

🛡️ 2. Che Giấu Vân Tay Trình Duyệt (Stealth Mode)

Google thu thập hàng chục thông số trình duyệt để phát hiện Headless Chrome:

  • Cờ Webdriver: Ghi đè Object.defineProperty(navigator, 'webdriver', {get: () => undefined}).
  • WebGL SwiftShader: Thay thế driver đồ họa ảo của Chrome headless bằng thông số GPU thực (Nvidia/AMD/Intel).
  • TLS / JA3 Fingerprint: Đảm bảo thứ tự Cipher Suites của thư viện HTTP trùng khớp 100% với trình duyệt Chrome thật.
  • Mô phỏng hành vi cuộn: Thêm delay ngẫu nhiên (1.2s - 2.8s) và cuộn chuột theo gia tốc (Bézier curve) thay vì nhảy cóc xuống đáy trang.

Thiết Kế Cơ Sở Dữ Liệu: PostgreSQL 16 + PostGIS Architecture

Schema chuẩn hóa tối ưu cho việc khử trùng lặp qua place_id (Upsert), lưu trữ thông tin liên hệ đa tầng (Emails, Social Profiles dạng JSONB), và truy vấn theo bán kính địa lý bằng hàm ST_DWithin:

schema_postgis_places.sql 
-- 1. Kích hoạt PostGIS để xử lý tính toán khoảng cách không gian
CREATE EXTENSION IF NOT EXISTS postgis;

-- 2. Tạo bảng lưu trữ địa điểm Google Maps chuẩn hóa
CREATE TABLE places (
    place_id VARCHAR(120) PRIMARY KEY,              -- ID duy nhất của Google để Upsert
    cid VARCHAR(64),
    title VARCHAR(255) NOT NULL,
    category VARCHAR(100),
    sub_categories TEXT[],
    address TEXT,
    city VARCHAR(100),
    state_province VARCHAR(100),
    country_code VARCHAR(10) DEFAULT 'VN',
    postal_code VARCHAR(20),
    latitude DOUBLE PRECISION NOT NULL,
    longitude DOUBLE PRECISION NOT NULL,
    geom GEOMETRY(Point, 4326),                     -- Tọa độ PostGIS chuẩn GPS WGS84
    phone VARCHAR(50),
    website TEXT,
    emails TEXT[],                                  -- Mảng chứa các email cào được
    social_profiles JSONB DEFAULT '{}'::jsonb,       -- Facebook, Instagram, LinkedIn...
    rating NUMERIC(2, 1),
    reviews_count INTEGER DEFAULT 0,
    price_level VARCHAR(10),
    opening_hours JSONB,
    is_claimed BOOLEAN DEFAULT FALSE,
    raw_data JSONB,                                 -- Lưu payload gốc đề phòng trích xuất thêm
    scraped_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Tạo Spatial Index và các Index tối ưu hóa truy vấn
CREATE INDEX idx_places_geom ON places USING GIST (geom);
CREATE INDEX idx_places_category ON places (category);
CREATE INDEX idx_places_city ON places (city);
CREATE INDEX idx_places_phone ON places (phone);

-- 4. Trigger tự động cập nhật trường PostGIS Point khi nạp latitude/longitude
CREATE OR REPLACE FUNCTION update_places_geom()
RETURNS TRIGGER AS $$
BEGIN
    NEW.geom := ST_SetSRID(ST_MakePoint(NEW.longitude, NEW.latitude), 4326);
    NEW.updated_at := NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_places_geom_update
BEFORE INSERT OR UPDATE ON places
FOR EACH ROW EXECUTE FUNCTION update_places_geom();

-- 5. Ví dụ câu lệnh nạp dữ liệu chống trùng lặp (Upsert ON CONFLICT)
INSERT INTO places (place_id, title, category, address, latitude, longitude, phone, website, rating, reviews_count)
VALUES ('ChIJz_4V2S0ZQjER...', 'Highlands Coffee', 'Cafe', '123 Bạch Đằng, Đà Nẵng', 16.068, 108.224, '02363849999', 'https://highlandscoffee.com.vn', 4.4, 850)
ON CONFLICT (place_id) DO UPDATE SET
    title = EXCLUDED.title,
    rating = EXCLUDED.rating,
    reviews_count = EXCLUDED.reviews_count,
    phone = COALESCE(EXCLUDED.phone, places.phone),
    website = COALESCE(EXCLUDED.website, places.website),
    updated_at = NOW();

-- 6. Truy vấn tìm kiếm địa điểm trong bán kính 2km từ tọa độ bất kỳ
SELECT place_id, title, address, phone, rating,
       ROUND((ST_Distance(geom::geography, ST_SetSRID(ST_MakePoint(108.2274, 16.0614), 4326)::geography))::numeric, 0) AS distance_meters
FROM places
WHERE category ILIKE '%cafe%'
  AND ST_DWithin(geom::geography, ST_SetSRID(ST_MakePoint(108.2274, 16.0614), 4326)::geography, 2000)
ORDER BY distance_meters ASC;
